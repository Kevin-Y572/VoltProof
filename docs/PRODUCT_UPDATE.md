# 需求验收与电路版本完善记录

本次实现将明确目标验收接到普通产品入口，并让运行证据对应具体电路版本。用户可以区分“运行完成”和“满足需求”；AI 预览只有在采用时才替换当前电路。

## 已实现

- 统一需求规格：目标、比较方式、容差、单位、节点、测量窗口；对话识别常见目标，也可在页面编辑。明确的元件修改增加参数检查。
- 统一判定：达标、未达标、验证不完整、未设置目标、已取消；缺少波形、无效数据和未知测量不会显示达标。
- 固定截止频率验收：按需求生成交流扫描与节点输出，原始候选、实际仿真网表和哈希分别保存。
- 草稿与版本：预览不改变项目，应用后才切换；撤销恢复网表、画布、分析和证据关系；修订号阻止迟到结果覆盖新编辑。
- 操作意图：解释、比较、原样验证、附件修改、诊断候选和设计。修改继承结构化约束与精简需求背景。
- 一致测量：瞬态按时间去除前 20% 暂态，均值/RMS 按时间积分；AC 保留相位并使用独立指标集合；截止点插值、节点歧义和观测不足给出原因。
- 证据体验：目标/结果/判定表、网表差异、交互波形、版本对比、缓存来源与原始运行时间。
- 参数扫描：识别 `DC value` 电源，每点独立保存网表/raw 并验收全部目标，合格点可以采用为新版本。
- 项目报告：汇集当前版本、手动画布、会话、AI 和参数扫描记录；保留按会话导出。
- MCP：结构化条件、结果与错误状态；默认验证零 LLM，修复需启用参数。
- 复现档案：修复轮次独立目录，记录仿真器版本、网表哈希、模型声明及测量版本；缓存包含供应商与相关代码指纹。
- 评测与分发：区分初次生成通过率与完整闭环 pass@1，跑批档案不覆盖；新增产品回归与隔离运行器；wheel 包含 HTML、JS、CSS。

## 验证方法

执行 `python scripts/test_isolated.py`。命令将 app、bench、tests 复制到项目内临时目录，使用空模型设置与固定 LLM 响应，实际运行 ngspice，避免清理真实工作区。五套测试覆盖原有离线能力、管线/API、基准验收、MCP 和产品业务回归，日志位于 `.test-results/`。

产品回归覆盖错误目标拒绝、真实修复、解析失败、预览丢弃、完整撤销、并发覆盖、附件修改、只验证、解释不改图、需求继承、未知目标、节点歧义、相位、时间统计、取消、固定交流验收、元件参数、版本对比、扫描采用及项目报告。

页面验证使用独立工作区和固定响应服务，不访问真实模型供应商，检查验收编辑、预览、丢弃、采用、撤销、对话、扫描、报告与窄窗口排版。

2026-10-18 收尾验证：产品回归 24 项通过，其余四套离线测试已通过。页面实测完成预览、采用、撤销、验收条件恢复、相位/节点/范围切换、版本对比、解释、扫描点采用及项目报告。额外修复撤销时扫描范围未恢复、旧候选结果卡残留和窄窗口对话页结果面板遮挡。

RC 扫描实测：C1=100nF 时，R1=1kΩ、1.59kΩ、2kΩ 对应截止频率约 1591.48Hz、1001.10Hz、795.93Hz；以 1kHz±5% 验收，只有 1.59kΩ 达标。Python wheel 已在本机构建并检查新模块和全部页面资源；没有进行新的 Windows EXE 构建。

## 适用范围与后续工作

自动语言识别覆盖常见明确表达，尚不承担任意需求的完整形式化。一阶低通/高通截止频率已经固定测量设置；混合多分析目标和功耗/阻抗等指标仍需专用测量。原样验证保持元件和连接，声明截止频率目标时会独立配置交流分析。

版本对比读取已有证据，不代表已经统一输入、负载和工况重新仿真。取消为阶段间协作式取消：正在进行的模型调用仍受调用超时约束，返回后不会采用电路。

本次没有重新运行收费模型的全量基准，也没有进行教师/学生招募。标准阻容值搜索、容差/温度/负载分析、课程管理和批量验收继续根据真实试用反馈推进；试用准备材料见 `TEACHING_PILOT.md`。
