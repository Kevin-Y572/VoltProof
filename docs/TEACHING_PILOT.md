# RC 低通实验试用方案

目标：观察学生能否借助明确验收与仿真证据，独立完成提出目标、发现偏差、修改和重新验证。

建议对象为一名教师和 5–10 名学生。先使用手动画布完成实验，无需模型密钥；有模型配置时再体验 AI 候选与诊断。此文是试用准备材料，不表示已经开展课程试验。

## 实验任务

1. 建立 RC 一阶低通：R=1.59 kΩ、C=100 nF、输入 AC 1 V，输入节点 in，输出节点 out。
2. 在“验收条件”设置截止频率 1000 Hz、容差 5%、低通。运行交流扫描，找到目标、结果与判定。
3. 将电容改为 200 nF，先预测截止频率，再仿真并记录未达原目标的原因。
4. 保持 C=200 nF，将电阻改为约 795 Ω，重新验证 1 kHz 目标。
5. 比较两个版本、查看交互波形、导出项目报告，解释 R、C 与截止频率的关系。
6. 可选：要求 AI 保持 C=200 nF 并恢复 1 kHz，查看候选差异，分别尝试丢弃、采用和撤销。

|---|---|---|---|---|---|
| | | | | | |

记录是否出现错误通过、是否误把旧版本当作当前电路，以及是否理解“未设置目标”和“验证不完整”。

## 访谈问题

- 哪一处信息帮助你判断电路是否符合目标？
- 电容翻倍后，你能根据波形和指标解释变化吗？
- 采用、丢弃、撤销后，你是否清楚当前是哪份电路？
- 报告是否足够支持你与教师讨论实验结果？
- 下一次实验中，你最希望产品帮助完成哪个步骤？

试用后先处理阻碍独立完成实验的问题，再决定是否加入分级提示、教师验收模板或批量作业能力。
